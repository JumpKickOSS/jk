# fqcn-baseline.txt — why each package-qualified reference that survives `jk format` survives.
#
# The house rule is "no FQCN except collisions" (docs/contributors/code-as-art.md, House rules ->
# Java 25). It is enforced by the `no-fqcn` guard (jk-guards.toml, G11), whose per-file counts are
# the `[no-fqcn]` entries in jk-guards-baseline.toml: a listed file may only shrink, an unlisted file
# must have none. That baseline is the count of record; this file is not read by any check. It keeps
# the reason each file is listed, which a baseline entry has no room for. (Until 2026-09-06 a Gradle
# `checkNoFqcn` task enforced this file itself; the task and the Gradle build are gone.)
#
# What a package-qualified reference is: two or more all-lowercase dot-separated segments followed
# by an UpperCamel identifier, in code — comments, string literals and the file's own
# `import`/`package` lines do not count.
#
# Who shortens: `jk format`'s import pass (plugins/formatter, `FqcnShortener` over a `TypeIndex` of
# the project's own top-level types and the JDK's). It reads the blanked source text, not a parse
# tree, so no file is ever out of its reach; a reference survives for one of the reasons below.
# Before 2026-08-26 this pass was OpenRewrite's, and this file's sections described its limits.
#
# FORMAT. One entry per line: `<count>  <path from the repo root>`, sorted by path within a section,
# the count copied from the file's `[no-fqcn]` entry. Measured 2026-10-31: 54 files, 101 references.
# When a baseline entry shrinks or goes, change or drop the line here in the same commit.


## collisions
# A genuine collision keeps its FQCN — this is the exception the house rule already grants, and
# every entry here names what the simple name is already taken by.

# The CLI test facade is itself `NewScaffolder`, so the production
# `cc.jumpkick.scaffold.NewScaffolder` it delegates to cannot be imported.
    3  clients/cli/src/test/java/cc/jumpkick/command/NewScaffolder.java

# `Javadoc` is claimed twice by Zinc's own API surface: `sbt.internal.inc.javac.Javadoc` (imported,
# because it owns the `local()`/`fork()` factories) and `xsbti.compile.Javadoc`, which is what they
# return. One of the two has to be spelled out and it is the return type.
    1  plugins/java-compiler/src/main/java/cc/jumpkick/java/compiler/ScalaBridge.java

# `JavaCompiler` is claimed twice by Zinc's own API surface: `xsbti.compile.JavaCompiler`
# (imported, because it is the type this worker hands Zinc) and `sbt.internal.inc.javac.JavaCompiler`,
# whose `local()`/`fork()` build one. The remaining reference is that second name. It was 13 before
# a later pass split the Zinc SPI adapters and the scalac construction into their own files; the
# `javax.tools.JavaCompiler` half of the collision left with ProvenanceJavac and the `Javadoc` half
# with ScalaBridge above.
    1  plugins/java-compiler/src/main/java/cc/jumpkick/java/compiler/ZincJavaCompiler.java

## wildcard-imports
# The shortener adds no import to a file with a wildcard import, `static` included: a wildcard can
# already be supplying any simple name, and a new single-type import could take it from the code
# that relies on it. Replacing the wildcard with the members it brings in frees the file.
   17  server/engine/src/main/java/cc/jumpkick/runtime/PlannerNative.java
    5  shared/core/src/main/java/cc/jumpkick/config/ManifestProject.java


## third-party-types
# The shortener's index holds the project's own types and the JDK's, not its dependencies'
# (`org.junit…`, `org.assertj…`, `com.google…`, Zinc's `xsbti`/`sbt`), so it cannot tell whether a
# third-party simple name is free in the file. These stay qualified until the hand edit (add the
# import, drop the package) is made; `jk format` never undoes one.
