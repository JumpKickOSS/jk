Seven reasons to switch

Every claim links what backs it, and the linked pages say where JumpKick still loses.

01

Agent-first

  • target/jk-results.md: one token-cheap report per run, each failure at its file:line with a fix hint, and what was skipped.
  • MCP built into the engine: run returns a verdict, deps and manifest edit the project and relock.
  • jk skill, the playbook for a tool models were not trained on, kept current in your AGENTS.md.
  • jk graph: a code graph built in. Nothing to install, indexed in seconds, with call edges from the compiled classes; every answer names Owner.member() at file:line.
  • Named test rungs: the cheap unit suite by default, --guard before you share, --all nightly.
  • Measured on 165 broken builds: agents reach green in as few or fewer turns than on Maven or Gradle.
  • Asked who calls a method, agents from three vendors answer every question with jk graph callers, in a fifth to two fifths of the turns they take without it.
The agent-loop table, gaps included →
02

Never type clean again

Every step is keyed by the content of its inputs and restored from a content-addressed store. A second worktree, another agent, or CI at the same commit restores the first one's work, and jk explain forecasts it before it runs.

The clean-build oracle →
03

Fast and frugal

A native client and one resident engine for every project on the machine, its heap capped and trimmed back after every job. Compilers and test JVMs lease memory from one budget and learn what they really use.

The measured table →
04

See what your agent is doing

jk web is the supervisor's view: every run with who asked, what changed since the last attempt, why it failed, and how long it took. The terminal shows the same facts with an honest ETA.

The dashboard →
05

Batteries Included™

JDK and Node.js toolchains, format, null checking, lint, house-rule guards, code generation, fat and minified jars, native images, OCI images, AOT training, SBOMs and audit, signing, release and publish. No plugin hunt.

What ships in the binary →
06

A modern, declarative core

jk.toml is data, never a program. jk-lock.toml is law. PubGrub explains conflicts in prose. Git dependencies, workspaces with one lockfile, and the newest stable versions by default.

Concepts →
07

Switch without a rewrite

jk test runs on an unmodified pom.xml, and jk mvn runs your real Maven build with the same results file. jk import when you are ready. Your ~/.m2 and IntelliJ JDKs are shared, not duplicated.

Quick Install

Shell

Install the latest jk with curl (Linux / macOS):

Terminal
curl -fsSL https://jumpkick.build/install.sh | bash

Or on Windows with PowerShell:

PowerShell
irm https://jumpkick.build/install.ps1 | iex

First build

A new project, or cd into an existing Maven one and start at jk test:

Terminal
jk new my-app && cd my-app
jk add jackson3-databind
jk test
jk web

Point your agent at it: jk skill prints the playbook, and jk mcp is the MCP server.
