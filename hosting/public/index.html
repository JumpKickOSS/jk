02 · Intelligence

Give your agent understanding — not another search expedition.

Built-in semantic navigation and MCP connect your agent directly to your code and development tools. Find callers. Follow relationships. Make informed changes.

We asked coding agents from 6 vendors questions like "who calls this method?" With jk's code graph, they answered in 66–91% fewer back-and-forth turns and used 72–98% fewer tokens than without it. Renaming a method everywhere it is used took 75–91% fewer turns and 78–98% fewer tokens. The graph pays off even on tiny projects: the smallest we tested, gs-multi-module, has just 83 lines of code.

Get started

One line to install. One more to build.

Shell

Install the latest jk with curl (Linux / macOS):

Terminal
curl -fsSL https://jumpkick.build/install.sh | bash

Or on Windows with PowerShell:

PowerShell
irm https://jumpkick.build/install.ps1 | iex

First build

A new project, or cd into an existing Maven one and start at jk test:

Terminal
jk new my-app && cd my-app
jk add jackson3-databind
jk test
jk web

jk new wires your agent in for you. On an existing project, run jk agents.
