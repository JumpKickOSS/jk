# cycle-baseline.txt — the ratchet behind `checkPackageCycleBand` (G67).
#
# One line per module that has a package cycle:
#
#     <module-rel> <packages sitting in a cycle>
#
# An absent module means 0, the convention `walk-baseline.txt` already uses. A count is the number
# of that module's production packages inside a non-trivial strongly-connected component of its own
# package-import graph — not a number of cycles. A 15-package component has thousands of elementary
# cycles and naming them would tell nobody which edge to cut.
#
# BOTH DIRECTIONS FAIL. Over the band is a regression: cut an edge, or widen the line and say why.
# Under the band means this file is loose — the commit that improved the structure must bank it, and
# the guard prints the tightened line to paste in. A number nobody tightens stops meaning anything.
#
# A ban would be the better rule and is unwinnable today: 49 of 95 production packages sit in a
# cycle, and two components are 15 and 10 packages inside the two largest modules in the tree.
# The charter's order is a ban, else a ratchet, else nothing.
#
# 2026-09-07: the engine root stopped being a hub. Its leaf types moved to `engine.api` (a package
# that imports no other engine package), worker budgeting to `engine.plugin`, and the listen
# package publishes through the `SseEvents` surface; the 15-slice component became three — the
# planner core (runtime, task, compile, test), the MCP front (http, http.mcp, http.mcp.tools) and
# the job/journal pair — so the engine line is 9. The two remaining edges that would dissolve the
# planner core are compile→runtime (GroovycInputs reads CompileSupport.collectJavaSources) and
# test→runtime (AffectedTestRun reads BuildPlanner's plan keys and Inputs).
#
# Measured at landing: 1,432 main sources, 95 packages, 29 module source roots, 195 resolved
# package edges. Method: per module, resolve each `import cc.jumpkick.*` to the longest declared
# package prefix WITHIN that module, then Tarjan over the resulting package graph. Imports that
# leave the module are dropped — a cross-module edge cannot close a cycle the module graph already
# forbids. `clients/intellij` is outside the scan (see PackageGraph.outsideTree).
#
# Shrinking any of these is per-module follow-up work. This file makes the number one the build
# defends.
